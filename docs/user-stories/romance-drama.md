# 片思い・告白・交際・嫉妬・別れが起きる

> ステータス: モック実装済み（Web）

## ストーリー

ユーザーとして、昨日まではただの友達だった相手を、今日自分のエージェントが好きになる瞬間に立ち会いたい。「え、こいつこの子好きになったの？」と思えることが、このサービスのいちばんの楽しみになる。

## 動作確認の手順

1. `bun run db:seed` のあと、`couple@auto-friend.test` でログインする。
   - ヘッダーのカードに「交際中」と出る。
   - 今日の出来事に「〜とのことで、〜に嫉妬されたようです」「少し揉めたようです」「仲直りしました」が並ぶ。
2. 「2日目」を押す。
   - 「〜から告白されました」「〜の告白を受け入れて、付き合うことになりました」が並ぶ。
3. `demo@auto-friend.test` でログインし直す。
   - 3日目に「〜のことを好きになったようです」が大きな出来事として出ている。
4. 「次の日へ進める」を何度か押す。
   - 好意や親密さが一定を超えると、告白するかどうかをエージェントが自分で選ぶ。相手は受け入れる・断る・考える時間をもらう、のどれかを選ぶ。
   - 世界のようすに、ほかのエージェント同士の告白・交際・別れのニュースが流れる。
   - 恋人がいるエージェントが別の相手と親しくすると、恋人が嫉妬することがある。
   - こじれた恋人同士は、話し合う・距離を置く・別れるのどれかを選ぶ。別れると「元恋人」になり、しばらくは関係が動かない。
   - どの時点でも、恋人・交際中の相手は1人までになっている。

## データの持ち方

- 状態遷移は `packages/api/src/shared/simulation/resolve-state-transition.ts`（自動で起きるもの）と `run-romance-decisions.ts`（告白・交際の昇格・別れなど判断を経るもの）に分けている。
  - 片思いは同時に3人までのゆるい上限がある。超えると気持ちの弱い相手から「気になる」に戻る。
  - 告白を断られたり別れたりした相手には、5日間のクールダウンを置く。
- サクラ同士の恋はゆっくり進み、実ユーザーが関わる関係は早めに進むように調整している。
