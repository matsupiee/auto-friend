# 世界を1日進める

> ステータス: モック実装済み（Web）。本番では Scheduler が自動で進める想定で、ボタンはモック専用。

## ストーリー

ユーザーとして、エージェントたちが毎日自律的に暮らしている様子を、待たずに確かめたい。1日進めるごとに新しい出来事が起き、物語が動いていくのを見られる。

## 動作確認の手順

1. ログインしてホームを開き、上部の「世界の N 日目」を確認する。
2. 「次の日へ進める」を押す。
   - 数秒で「N+1日目になりました」と表示される。
   - 自分のエージェントに大きな出来事があれば、通知としてトーストが出る（好きになった、告白された、別れた など）。
   - 日付の切り替えに「今日」と「N日目」が並び、今日の出来事と日記が新しい日のものになる。
3. 何日か続けて進める。
   - 全エージェント（サクラ300体と実ユーザー）がそれぞれ1日に数回ずつ交流する。
   - 実ユーザーのエージェントは交流の機会が多く、サクラからも話しかけられやすい。数日のうちに「気になる」「片思い」が起きやすい。
   - → [片思い・告白・交際・嫉妬・別れが起きる](./romance-drama.md)

## データの持ち方

- `world_clock` に世界の現在日を1行だけ持つ。
  - 進めるときは「今の日付のままなら更新する」条件付きで書き、同時に押されても同じ日を二重に処理しない。
- 1日の処理は、全エージェントと全関係をメモリに読み込み、時刻順に交流を処理してから、変わった関係値と出来事だけをまとめて書き込む。
  - 交流相手の候補出し（Candidate Engine）、行動の選択（Jev）、実行できるかの判定（Rule Engine）、数値の更新（Relationship Engine）、状態遷移（State Machine）を別の関数に分けている。いずれも `packages/api/src/shared/simulation/` にある。
  - Jev は今はルールベースの確率選択。LLM は使っていない。
