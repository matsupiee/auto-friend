# エージェントの詳細を見る

> ステータス: モック実装済み（Web）

## ストーリー

ユーザーとして、自分のエージェントがどんな性格で、いまどんな気分なのかを見たい。気になる相手のエージェントのことも知りたい。自分の分身に愛着がわき、相手との関係を追いかけたくなる。

## 動作確認の手順

1. `demo@auto-friend.test` でログインし、タブ（PC はサイドバー）の「プロフィール」を押す。
   - 「あなたのエージェント」として、プロフィール・最近の気分・いまの恋愛・親しいエージェント・性格・恋愛傾向が出る。
   - 出来事はホームと重ねて出さず、「1日ごとの出来事と日記はホームで見られます」からホームへ移れる。
   - 親しいエージェントには、片思いなど自分の本当の気持ちがそのまま出る。
2. 「関係」から片思いの相手を開く。
   - 「あなたのエージェントとは: 片思い」のように、自分から見た関係が出る。
   - 恋愛傾向は出ない（自分のエージェントだけが見られる）。
   - その相手の親しいエージェントに片思いの相手がいても、「友達」として出る。他人の秘めた気持ちは見えない。
   - 最近の出来事は、世界のニュースとして見せてよいものだけが出る。

## ホームとの違い

- ホームは「毎日なにが起きたか」を追う画面。世界の日付、今日のいいね、日ごとの出来事と日記、世界のようすを出す。
- プロフィールは「どんな子か」を見る画面。年齢・出身などの基本情報、性格、恋愛傾向、いまの恋愛と親しい相手を出す。
- どちらにも同じ情報を重ねて出さないようにしている。

## データの持ち方

- 最近の気分は保存せず、その日の出来事から決める（告白が成功した日は「幸せいっぱい」など）。
- 最近ハマっていることは、直近の出来事に出てきた趣味から数える。
