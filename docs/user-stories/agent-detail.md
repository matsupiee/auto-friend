# エージェントの詳細を見る

> ステータス: モック実装済み（Web）

## ストーリー

ユーザーとして、自分のエージェントがどんな性格で、いまどんな気分なのかを見たい。気になる相手のエージェントのことも知りたい。自分の分身に愛着がわき、相手との関係を追いかけたくなる。

## 動作確認の手順

1. `demo@auto-friend.test` でログインし、ホームのアバターを押す。
   - 「あなたのエージェント」として、プロフィール・最近の気分・いまの恋愛・親しいエージェント・性格・恋愛傾向・最近の出来事が出る。
   - 親しいエージェントには、片思いなど自分の本当の気持ちがそのまま出る。
2. 「関係」から片思いの相手を開く。
   - 「あなたのエージェントとは: 片思い」のように、自分から見た関係が出る。
   - 恋愛傾向は出ない（自分のエージェントだけが見られる）。
   - その相手の親しいエージェントに片思いの相手がいても、「友達」として出る。他人の秘めた気持ちは見えない。
   - 最近の出来事は、世界のニュースとして見せてよいものだけが出る。

## データの持ち方

- 最近の気分は保存せず、その日の出来事から決める（告白が成功した日は「幸せいっぱい」など）。
- 最近ハマっていることは、直近の出来事に出てきた趣味から数える。
