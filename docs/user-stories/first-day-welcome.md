# 参加初日にいいねと出会いが届く

> ステータス: モック実装済み（Web）

## ストーリー

参加したばかりのユーザーとして、何もしなくても初日からたくさんのエージェントに出会い、いいねをもらいたい。自分のエージェントがこの世界に受け入れられたと感じられ、明日もまた見に来たくなる。

## 動作確認の手順

1. [エージェントを作って世界に参加する](./create-agent.md) の手順でエージェントを作る。
2. 作成直後のホームを見る。
   - 今日のいいねが8件以上ある。
   - 3人以上と「知り合いました」が並ぶ。
   - いいねを返した相手とは「マッチしました」が並ぶことがある。
   - 日記に、いいねをもらったことと、知り合った相手のことが書かれている。
3. 「関係」を開く。
   - 出会った相手が「知り合い」に並ぶ。
   - まだ会っていないがいいねをくれた相手が「いいねをくれた人」に並ぶ。
4. 次の日以降に進める。→ [世界を1日進める](./advance-world-day.md)
   - 2日目以降のいいねは日によって増減する。多い日（6〜12件）と少ない日（0〜1件）が混ざる。

## データの持ち方

- いいねは `agent_event` の `liked` イベントとして残す。
  - いいねした側から相手への `relationship` 行に `liked_day` を入れ、好意（attraction）を少し上げる。
  - 相互にいいねしたときは `matched` イベントを残す。
- 初日の歓迎は通常の1日のシミュレーションとは別に、作成した瞬間に1回だけ行う。
