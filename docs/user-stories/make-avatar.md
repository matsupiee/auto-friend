# パーツを組み合わせて見た目（アバター）を作る

> ステータス: モック実装済み（Web）

## ストーリー

エージェントを作るユーザーとして、トモダチコレクションの Mii づくりのように、輪郭・髪型・目・口などのパーツを選んで組み合わせ、自分の分身の見た目を作りたい。絵が描けなくても、選んで位置や大きさを整えるだけで「この子らしい顔」ができるので、エージェントに愛着がわく。あとからいつでも作り直せる。

## 動作確認の手順

1. `bun run db:seed` で世界を作り直し、`bun run dev` でサーバーと Web を起動する。
2. 新しく登録し、エージェントの作成画面で基本情報（名前・性別・恋愛対象・生年月日）を入れて「次へ」を押す。
   - ステップ2/4「見た目」に進み、上部にアバターのプレビューが出る。
   - 最初は性別に合わせた「おまかせ」の見た目になっている。女性ではヒゲは生えない。
   - → [エージェントを作って世界に参加する](./create-agent.md)
3. 上部のタブでパーツの種類を切り替え、パーツを選ぶ。
   - タブは 輪郭・髪型・眉・目・鼻・口・ヒゲ・メガネ・ほくろ・体格・好きな色 の11種類。
   - パーツの一覧は、いまの顔にそのパーツを当てはめたサムネイルで並ぶ。選んだものにはチェックが付き、プレビューがすぐ変わる。
   - 色はパレットから選ぶ（肌・髪・眉・瞳・くちびる・ヒゲ・メガネのフレーム・好きな色）。
4. 「目」「眉」では上下・大きさ・傾き・間隔、「鼻」「口」では上下・大きさをスライダーで調整する。
   - 0 が標準で、決められた幅の外には動かせない。
5. 「体格」で身長と体型を変える。
   - 「体格」「好きな色」のタブでは、プレビューが全身表示になる。好きな色は服の色になる。
6. 「おまかせ」を押す。
   - 見た目が丸ごと作り直される。
7. 残りのステップを進めてエージェントを作る。
   - ホームのアイコン、出来事・関係一覧に並ぶ相手のアイコンが、それぞれのエージェントの似顔絵になる。
8. 自分のエージェントのプロフィールを開く。
   - 似顔絵が全身で表示される。
   - 「見た目を編集」ボタンがあり、押すと /avatar に移る。
9. /avatar でパーツを変える。
   - 作成時に選んだパーツが選択された状態で開く。
   - 変更がないうちは「この見た目で保存」を押せない。「元に戻す」で開いたときの見た目に戻る。
   - 保存するとプロフィールに戻り、新しい見た目になる。関係や性格、出来事は変わらない。
10. 他人のエージェントのプロフィールを開く。
    - 全身の似顔絵は見えるが、「見た目を編集」ボタンは出ない。

## データの持ち方

- `agent.avatar` に、パーツの組み合わせを JSON で持つ。
  - 中身は輪郭・髪・眉・目・鼻・口・ヒゲ・メガネ・ほくろ・体格・好きな色。パーツと色は id、位置や大きさは 0 を標準とする整数。
  - id の一覧と調整幅は `packages/avatar/src/avatar-parts.ts`、形のチェックは `packages/avatar/src/avatar-schema.ts` にまとめ、API の入力チェック・seed・画面で共有する。
  - パーツの見た目（SVG）は `apps/web/src/components/avatar/parts/` に、同じ id で1つずつ用意する。保存されるのは id だけなので、パーツの絵を描き直しても保存済みのアバターはそのまま新しい絵で表示される。
  - null を許す。null のエージェントは、エージェントの id から毎回同じ見た目を作って表示する（API の `resolveAvatar`）。
- 見た目は `appearance`（ユーザーに見せない魅力度）とは関係しない。見た目を変えても相性やいいねの数は変わらない。
- サクラエージェントは seed でランダムに見た目を決める。世界の乱数とは別に決めるので、見た目のパーツを増やしても関係や出来事の生成結果は変わらない。デモユーザー（ハル・ミナ）は固定の見た目にしている。
