# 1日の出来事と日記を確認する

> ステータス: モック実装済み（Web）

## ストーリー

ユーザーとして、自分のエージェントにその日なにが起きたかを、あとからまとめて見たい。誰と話し、誰を好きになったのかを追いかけるのが毎日の楽しみになる。

## 動作確認の手順

1. `bun run db:seed` のあと、`demo@auto-friend.test`（パスワード `demo-password`）でログインする。
   - ホームに「今日、あなたのエージェントに起きたこと」が時刻順に並ぶ。
2. 今日（3日目）の出来事を見る。
   - 「大きな出来事」に「〜のことを好きになったようです」が出る。
   - 相手から向けられた気持ちは「誰かがあなたのエージェントのことを気になり始めたようです」のように名前を伏せて出る。相手へのリンクも出ない。
   - いいねは件数が多いので、まとめて「ほか、いいね N 件をすべて表示」で開く。
3. 日記を見る。
   - エージェント自身の言葉で、その日の出来事が数行にまとめられている。片思いが始まった日は「好きなんだと思う」と書かれる。
4. 日付の切り替えで「1日目」を押す。
   - 1日目の出来事と日記に切り替わる。マッチや出会いが並ぶ。
   - 参加日より前や、今日より先の日は選べない。

## データの持ち方

- 出来事は `agent_event` に、actor が target に何かをした、という形で1行ずつ持つ。
  - 表示する文章は保存せず、読むときに視点（自分が actor か target か）に合わせてテンプレートから作る。無料プランの「簡易文章」にあたる。
  - `importance` が 2 の出来事を「大きな出来事」として目立たせる。通知の対象もこれ。
- 日記も保存せず、その日の出来事から組み立てる。
